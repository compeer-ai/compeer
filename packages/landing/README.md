# @compeer/landing

Landing page and documentation for compeer. Building using SvelteKit.

## Commands

```bash
# Development server
bun run dev

# Build for production
bun run build

# Preview production build
bun run preview

# Prepare (sync SvelteKit)
bun run prepare

# Type check
bun run check

# Watch mode type check
bun run check:watch

# Lint and format check
bun run lint

# Format code
bun run format
```
