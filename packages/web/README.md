# @compeer/web

The web application and backend server for compeer. Built using SvelteKit.

## Commands

```bash
# Development server
bun run dev

# Build for production
bun run build

# Prepare (sync SvelteKit)
bun run prepare

# Type check
bun run test:types

# Run tests
bun run test

# Format code
bun run format

# Check formatting
bun run lint:format

# Generate API docs
bun run generate:docs
```
