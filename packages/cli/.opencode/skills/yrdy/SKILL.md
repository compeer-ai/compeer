# yrdy

## Search Knowledge Base

You can search this knowledge base using the `search` command. Example:

```bash
compeer search "hello world" "yrdy" "Frontend design specification"
```

## Add to Knowledge Base

If you need to remember something to be searched later, use the `capture` command.

Example of capturing text:

```bash
compeer capture "hello world" "yrdy" "This project is for UI development"
```

Example of capturing a website:

```bash
compeer capture "hello world" "yrdy" "https://compeer.ai"
```

Example of capturing a data payload:

```bash
compeer capture  "hello world" "yrdy" "{'hello': 'world'}"
```
